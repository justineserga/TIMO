# TIMO

Attendance and Payroll System

This repository currently holds the admin frontend, based on the [Mantis Vue](https://themewagon.com/themes/Mantis-Vue/) Material admin template.

## Local development (Docker)

```bash
docker compose up --build
```

The dev server is available at [http://localhost:5175](http://localhost:5175).

## Local development (without Docker)

1. Install dependencies:

```bash
npm i
```

2. Run the development server:

```bash
npm run dev
```
